# TechService Manager
Учебный проект для производственной практики ПП.02.


Информационная система для производственной практики ПП.02 по модулю ПМ.02
«Осуществление интеграции программных модулей».

## Что реализовано

1. Учёт клиентов.
2. Учёт оборудования клиентов.
3. Создание заявок на техническое обслуживание.
4. Изменение статусов заявок.
5. История взаимодействий с клиентами.
6. Сохранение данных в SQLite.
7. Демонстрационное заполнение базы.

## Как запустить

1. Установить Python 3.
2. Открыть проект `techservice-manager`.
3. Запустить команду:

```powershell
python server.py
```

4. Открыть в браузере:

```text
http://127.0.0.1:8000
```
# Также в репозитории представлена HTML-версия сайта информационной системы `TechService Manager`. 
Она включает пользовательский интерфейс для работы с клиентами, оборудованием, заявками, статусами и историей взаимодействий. 
Проект можно запустить локально через Python-сервер, после чего открыть сайт в браузере по адресу 
```text
http://127.0.0.1:8000
```

## Состав проекта

1. `server.py` — серверная часть на Python и работа с SQLite.
2. `index.html` — интерфейс системы.
3. `styles.css` — оформление страниц.
4. `app.js` — клиентская логика и запросы к серверу.
5. `techservice.db` — база данных, создаётся автоматически после запуска.
